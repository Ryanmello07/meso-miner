# v3.23.0-fix.33.0-rc5

> [!NOTE]
> Fifth pre-release of the v33 line: rc4 plus the operator-facing completion work. It adds the Docker operator environment passthrough, `provider snclaim`, `choose_network --show`, three durable-head publication fixes, and the CFAA blocklist refresh. The provider code here is the v33 release candidate (`e9dd5b70d`). Not a stable release: it is invisible to `urnet-tools update`. Try it on one box first.

## Highlights

- **Docker operator passthrough.** The v33 operator environment variables map onto provide flags, and `ALL_OPERATORS` replaces the single `AUTH` login. The container quick start is rewritten around `AUTH`.
- **`provider snclaim` and `choose_network --show`.** Submit a claim from the provider binary, or print the network choice without applying it.
- **Durable-head publication.** A stop keeps every prepared record and abandons only an unwritten publication; the create-marker lifecycle gaps are closed; a cancelled publication no longer strands a snapshot temporary.
- **CFAA blocklist refresh** for the v33 tag.
- **Docs**: the rc5 operator, snclaim and fan-out surface is documented; vnStat is retired in the container docs and metadata.

## Fixed

- Durable-head publication after a stop, create-marker lifecycle, and cancel paths (three separate fixes).
- Claim queue publication.
- Test ordering: the H3 send harness publication is ordered, and the ICMP echo view skips without ICMP sockets.

## Known limits

- Same as rc4; the client send path for ICMP stays off.
- Prereleases are not offered by `urnet-tools update`.
