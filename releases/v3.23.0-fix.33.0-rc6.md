# v3.23.0-fix.33.0-rc6

> [!NOTE]
> Sixth and final pre-release of the v33 line. This is a **test-only** release: the provider code is identical to rc5, built from `e9dd5b70d`; the only changes are in the release shakedown harnesses. It exists so the repaired checks run against a tag before the stable release. Not a stable release: it is invisible to `urnet-tools update`.

## Highlights

- **Test-only release.** The provider code is identical to rc5 (`e9dd5b70d`); the only changes are in the release shakedown harnesses. It exists so the repaired checks run against a tag before the stable release.

## Fixed

- **Docker shakedown Y5 and W5.** Y5 now seeds the compose volume it later asserts, and W5 parses the URL-source failure line and asserts the bound, instead of failing on harness artifacts.
- **Client-ID shakedown race.** The check now stops the provider before clearing the client-JWT store, so a restart cannot race the clear.

## Compatibility

- Runtime and on-disk behavior are identical to rc5 (`e9dd5b70d`). Units, dashboards and state directories need no changes.

## Known limits

- Prereleases are not offered by `urnet-tools update`.
