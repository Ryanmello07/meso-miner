# v2026.10.19-1075696970-meso — 2026-10-19

> [!NOTE]
> This is the meso-miner release corresponding to `urnetwork-3.23-fix` [`v3.23.0-fix.33.0`](https://github.com/full-bars/urnetwork-3.23-fix/releases/tag/v3.23.0-fix.33.0). It carries the same engine and provider work on the v2026 connect line, plus the CFAA refresh that ships with the 33.0 cutoff. Nodes on `v2026.10.6` or older should rebuild and redeploy.

## 1. The story of this release

The last meso release closed runtime parity with the fork. This one hardens what that runtime does under load: the reconnect governor and outage data-plane work land here, the transfer custody path gains retry budgets and silence bounds, and the security/audit layer learns to tell a saturated box from a broken one. On top of that, OpenRC and FreeBSD become first-class install targets, and the CFAA blocklist is refreshed through the same cutoff the 3.23 fork used for 33.0.

## 2. Reconnect governor and outage hardening (PRs #208, #209, #218)

- Reconnect governor ported from the v2026 engine, with an outage-protection data plane: retransmission bounds, dead-client release, and a shadow-by-default rollout path.
- Follow-up pass on the CodeRabbit findings from #209, including the eviction threshold and the heap-over-limit exception now documented and enforced.
- Diagnostics no longer judge goroutine growth during the startup ramp (#198), so a busy start stops reading as a leak.

## 3. Transfer custody and retry bounds (PRs #204, #205, #206)

- Retained sequences whose destination acknowledges nothing are ended instead of held forever.
- Resends are bounded by a retry budget.
- The retained-byte budget is charged and released with the same amount, so accounting cannot drift under churn.

## 4. Security and egress hygiene (PR #211, CFAA syncs)

- IPv4-mapped IPv6 destinations are judged by the IPv4 tables, and special-use IPv6 ranges are refused.
- CFAA blocklist refreshed from upstream through #201, #212 and #214–#217, matching the 33.0 cutoff.

## 5. Platform support and operator tooling (PRs #202, #203, #210, #213)

- OpenRC lifecycle and installer support, with completed OpenRC and FreeBSD platform guides.
- Startup disk benchmark is bounded, safe, and skipped where it cannot help; deep state dirs are measured, and an unmeasurable state dir is no longer reported as a full disk.
- macOS and FreeBSD installers now do a single GitHub download with retries instead of a duplicate fallback path.
- Go 1.27.2 is required.

## 6. Self-heal

- A container provider that exits 75 restarts without an opt-in (#199), and a stalled container provider is recovered too (#200).

## Deploy Notes

1. Rebuild or pull the new image; native installs re-deploy the binary.
2. HotSwap engages without downtime once a node runs a hotswap-capable release and the unit is `Type=notify`.
3. The CFAA refresh is data-only; no operator action is required.
4. Go 1.27.2 is required to build from source.
